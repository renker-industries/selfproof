Checks AI-written code and records evidence for every check on a tamper-evident ledger.

Most AI guardrails ask the model to behave. Selfproof runs deterministic gates in git and CI for whichever agent wrote the code, and binds every result to an exact commit on a ledger anyone can recompute.

What it does

Deterministic gates

Slop, security, language and test-weakening checks run in git hooks and CI.

Any agent

Rules files for Claude Code, Codex, Cursor, Aider and Gemini CLI; hooks apply to all of them.

Evidence ledger

Each result is bound to a commit and written to a hash-chained ledger.

Strict claims

The strongest statement allowed is “0 known findings at commit X per tools Y on date Z”.

Installers

Windows installer and one-line installers for macOS, Linux and PowerShell are published as releases.

Honest limits

Read this first. Pre-release and bootstrapping: no version is supported for production use yet. Branch protection is a signed-approval workaround for a solo maintainer, the hash chain cannot detect a truncated tail except against release anchors, and the kernel does not yet cryptographically authenticate actors. Some concept components are still planned.
