# Prompts

## Autopilot master prompt

The autopilot master prompt is the **procedure** source of truth (the concept in
`docs/CONCEPT.md` is the **intent** source of truth). It carries the autonomy
charter, whose authorizations are mirrored in
[`../../AUTONOMY_CHARTER.md`](../../AUTONOMY_CHARTER.md).

**Provenance note (honesty, R1).** In the build session the prompt was delivered
inline, not as a file on disk, so this repository does not archive a byte-exact
copy. Archiving the owner's exact source file (and recording its SHA-256 in the
ledger and the charter) is a manual owner step tracked in
[`../reports/OWNER_TODO.md`](../reports/OWNER_TODO.md). Until then, the charter's
authorizations govern, and the concept plus this repository record the
procedure actually followed.
