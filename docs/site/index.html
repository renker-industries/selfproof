Or install with one line

macOS / Linux:

curl -fsSL https://raw.githubusercontent.com/renker-industries/selfproof/main/install.sh | sh

Windows (PowerShell):

irm https://raw.githubusercontent.com/renker-industries/selfproof/main/install.ps1 | iex

Phone (Android / iPhone)

There is no app store download. Open the dashboard page in your phone browser and choose “Add to Home Screen” — it gets its own icon and opens full-screen. See the guide.

All downloads are single files with no external resources. The macOS and Linux binaries are built on their own systems by CI. Until the project is public, these links work for people with access to the repository.
